# LSN-Michele-Brambilla
LSN 2026 Exercises

Nella repository GitHub sono raccolte le esercitazioni del corso di Laboratorio di Simulazione Numerica di Michele Brambilla, matricola 35022A.

Ho lavorato in ambiente Windows sulla mia macchina personale.
Per i notebooks ho lavorato su environment Miniconda.

Il materiale di ogni esercitazione è raccolto in una cartella dedicata. 
In una sottocartella, denominata **code**, è raccolto tutto il codice: solitamente main di ogni esercizio, makefile e dipendenze del main. Per eseguire gli esercizi è necessario modificarne il nome all'interno del makefile, ed eventualmente rimuovere alcune dipendenze. Per l'esercitazione numero 6 è stato utilizzato uno script python: è sufficiente eseguire quello per disporre di tutti i file di output dell'esercizio.

Per quanto riguarda i notebooks, ho cercato di motivare le scelte fatte nel corso della conduzione degli esercizi, collegando le stesse e i risultati ottenuti alla teoria illustrata a lezione.
